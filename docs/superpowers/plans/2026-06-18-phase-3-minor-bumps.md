# Phase 3 — Low-risk version bumps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bump the batch of small, independent dependencies (tRPC to stable, react-query, env/zod/types-node, UI/utility minors, dev formatting tools) without touching anything reserved for later phases (React, Next, Prisma, Tailwind, ESLint, NextUI, framer-motion, Zod major, Better Auth, moment, lodash).

**Architecture:** Four sequential commits on `chore/upgrade-phase-3-minor-bumps`, one per dependency group from the spec, each followed by the fast gate (`yarn lint && npx tsc --noEmit && yarn build`) so a break is isolated to the commit that caused it. `yarn e2e` runs once at the end, not per-commit. A final commit updates the master-plan tracking table and opens the draft PR.

**Tech Stack:** Next.js 14, tRPC 11, TanStack Query 5, Yarn 1, TypeScript, Zod 3, Prettier.

## Global Constraints

- Stay on `chore/upgrade-phase-3-minor-bumps`, forked from `develop`.
- Do not touch: `react`, `react-dom`, `next`, `prisma`/`@prisma/client`, `tailwindcss`, `eslint`/`eslint-config-next`/`@typescript-eslint/*`, any `@nextui-org/*` package, `framer-motion`, `@internationalized/date`, `better-auth`, `moment`, `lodash`.
- Zod stays on v3 (no v3→v4 jump) and TypeScript stays on 5.x (no major) — only same-major forced bumps are allowed.
- A forced bump that requires a major version anywhere is out of scope — stop, leave the version unchanged, note as a follow-up instead of bumping.
- Fast gate after every commit: `yarn lint && npx tsc --noEmit && yarn build`. Must pass clean before moving to the next commit.
- `yarn e2e` runs once, after all four commits, not per-commit.
- Smoke-check tRPC (query + mutation round-trip, e.g. events calendar load + create/update) specifically after commit 1.
